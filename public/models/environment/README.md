# Environment exports

This directory is the destination for the future production `door.glb`. The game
uses the procedural door by default and does not request the missing file.

See the [Blender sources](../../../assets/blender/README.md#door--model-pending)
for the contract, editable-source destination, export settings, and activation
steps. Do not publish the test fixture as final art. The Echo is exported
separately to `public/models/characters/echo.glb`.
